# Dreamscrol

A vertical, swipe-one-at-a-time feed of homes for sale. Video first, price on top, likes, comments and shares.

| File | What it is |
|---|---|
| `prototype.html` | Clickable prototype with made-up Metro Detroit listings, buying power, lender comparison and agent-linked offers. Best viewed from the published artifact link; it's written as a page fragment, so opening the raw file in a browser can look off. |
| `PLAN.md` | Strategy for a Detroit launch: the mortgage-first funnel, why agents post, Michigan rules, money, launch plan, risks and questions for counsel. |
| `MVP_SPEC.md` | What it takes to build: stack, data model, video pipeline, feed ranking, compliance features, phases, costs. |

Everything in the prototype is sample data. No real listings, agents or prices.
